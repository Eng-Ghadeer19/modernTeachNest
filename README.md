# 🎓 Teach Nest - Modern Educational Platform

Teach Nest is an interactive, modern educational platform designed to streamline course exploration and search. Built with a focus on seamless user experience, clean dynamic layout, and appealing visuals.

![Teach Nest Preview](img/1786727064062.jpg)

---

## ✨ Features

- 🔍 **Smart Search & Filtering:** Quickly search and filter courses across multiple tech domains (AI, CS, Cybersecurity, Data Science).
- 🎨 **Glassmorphism UI:** Clean, responsive design featuring modern visual cards and blue-themed palettes.
- 🎬 **Smooth GSAP Animations:** Interactive modal popups and smooth scroll transitions powered by GSAP & ScrollTrigger.
- 📱 **Fully Responsive:** Optimized for desktop, tablet, and mobile viewing.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Animation Libraries:** GSAP (GreenSock Animation Platform), ScrollTrigger
- **Styling Aesthetics:** Glassmorphism, Modern Card Layouts, Custom Typography
